# Pre-render checklist

- [ ] `npm run plate:verify` passes
- [ ] `npm run sync` run today; diff of `site-snapshot.json` reviewed
- [ ] `npm run audit` passes
- [ ] `npm run motion` clean (or exceptions recorded)
- [ ] `npm run stills` reviewed; contact sheets look right
- [ ] `npm run qr:check` passes
- [ ] Machine plugged in; nothing else heavy running; disk space at least 50 GB
- [ ] No dependency upgraded since the last QA
